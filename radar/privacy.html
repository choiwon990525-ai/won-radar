이 앱은

WON 레이더는 발로란트·AI 소식과 발로란트 꿀팁 영상을 모아 보여 주는 개인 코치용 앱이에요. 계정·로그인·광고가 없고, 쓰는 사람의 정보를 서버로 보내지 않아요.

Riot Games가 보증하지 않는 개인 팬 프로젝트예요. 각 소식과 영상의 권리는 원래 올린 곳에 있어요.

YouTube API 서비스

꿀팁 탭은 YouTube API 서비스로 공개 영상 정보(제목·채널 이름·올린 날·길이·썸네일 주소)를 받아 보여 줘요. 이 앱을 쓰면 YouTube 서비스 약관에 동의하는 거예요. YouTube가 정보를 다루는 방식은 Google 개인정보처리방침에 있어요.

  • 이 앱은 YouTube 계정에 접근하지 않아요. 로그인이나 권한을 묻지 않아요.
  • 영상 정보는 7일마다 다시 받아 바꾸고, 29일 넘게 다시 받지 못한 영상은 지워요. 조회수 같은 통계는 받지 않아요.
  • 어떤 영상을 보여 줄지는 코치가 정한 채널과 검색어로만 정해요. 앱이 영상 내용을 보고 종류를 매기지 않아요.

접속할 때 다른 곳에 남는 기록

이 앱은 GitHub Pages에서 열리고, 글꼴은 Google Fonts에서, 꿀팁 썸네일은 YouTube 서버(i.ytimg.com)에서 바로 불러와요. 이 회사들은 접속할 때 IP 주소 같은 기록을 각자 방침에 따라 남길 수 있어요. 썸네일을 불러올 때는 어느 페이지에서 왔는지(리퍼러)를 보내지 않게 해 두었어요.

이 기기에 남는 것

아래 정보만 이 브라우저 저장소(localStorage)에 남아요. 다른 곳으로 보내지 않아요.

  • 고른 탭, 마지막으로 본 시각, 이번 주 꿀팁을 봤다는 표시
  • 읽은 글 표시 (최근 3,000개까지)
  • 저장한 글: 소식은 그 글의 제목·주소·요약, 꿀팁은 영상 id와 코드만 (꿀팁 저장은 30일 뒤 지워져요)
  • 꿀팁 안내에 동의한 날

앱을 폰에 설치하면 화면 파일과 데이터 파일 사본을 브라우저 저장본(서비스 워커)에 둬요. 인터넷이 끊겨도 마지막으로 받은 내용을 볼 수 있게 하려는 거예요.
